# HackTown Founder-led Growth

Site estatico da palestra "Founder-led Growth: como transformar seu perfil pessoal no LinkedIn em um canal de aquisicao".

## Arquivos

- `index.html` - apresentacao principal.
- `pack-founder-led-growth.html` - landing do pack de 7 dias.
- `briefing-reestruturacao.html` - briefing editorial.
- `PROVENANCE.md` - origem de conteudo, assets e observacoes.
- `assets/` - imagens, logos e dependencias locais.

## Deploy

Qualquer host estatico funciona. Aponte o subdominio para o projeto e use `index.html` como entrada.
